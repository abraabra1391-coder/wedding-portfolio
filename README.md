# wedding-portfolio

AIORA MEDIA – Digital Invitation Collection.

A single-page portfolio of 24 live digital invitation websites (Muslim, Hindu and Christian weddings, birthdays, housewarming).

## Files
- `index.html` – the whole site (styles, script and project list inside)
- `covers/` – one preview image per project

## Editing
Open `index.html` and look for the `EDIT HERE` block near the bottom:
- `CONTACT` – WhatsApp number, pre-filled message, Instagram handle
- `PROJECTS` – name, category, link and cover image for each invitation. Copy a line to add a new one.

## Hosting
No build step. Import the repo into Vercel (Framework: Other) or turn on GitHub Pages – it serves `index.html` as is.
